## 光的性质

理解光，比先买灯更重要。可以从三个维度描述一束光：

| 维度 | 看什么 | 影响什么 |
| --- | --- | --- |
| **杂乱程度（柔/硬）** | 发光面积大小 | 阴影边缘锐利还是柔和 |
| **衰减程度（反差）** | 灯与主体的距离 | 主体与背景的亮度差异 |
| **聚散程度** | 格构、菲涅尔透镜等 | 光落在画面的哪些区域 |

### 硬光与柔光

- **硬光**：本质接近平行光，阴影干脆，气质硬朗。常见来源：正午太阳、裸灯点光源。
- **柔光**：散射光，明暗过渡平滑。灯越近，按平方反比规律，主体与背景的光比越大，背景往往更暗。

### 把光变柔的思路

1. **漫透射**：柔光罩、塑料袋、硫酸纸等挡在灯前。
2. **漫反射**：跳闪（打向天花板或墙面）、反光板补光。

**口诀：光源越近 → 过渡越柔和 → 反差越大。**

## 控制光

### 色温与白平衡

- **低色温**（约 3300K 以下）：偏暖。
- **高色温**（约 5300K 以上）：偏冷。
- 机内白平衡与色温数值**方向相反**：冷环境加暖、暖环境减暖；当白平衡 K 值等于现场色温时，白色被正确还原。

### 光比

主光与补光（或反光板）的亮度关系，主要由距离和功率决定。距离近，衰减快，反差大。

### 光区

用遮光工具「切」出想要照亮的一块，层次就清晰了：

- 黑旗、格栅/蛋格、遮扉
- Spotlight、剪影遮光板

**遮光控光 = 切出光区，凸显层次。**

## 入门设备

### 灯具类型

| 类型 | 特点 | 适合 |
| --- | --- | --- |
| **热靴闪光灯** | 瞬时输出；快快门时亮、慢门凝固主体；能压过环境光 | 照片、户外压暗背景 |
| **常亮灯**（灯棒/灯板/口袋灯/影棚灯） | 所见即所得；发光面形状多样 | 照片 + 视频 |
| **影棚常亮** | 保荣卡口，可接大型柔光附件 | 室内人像、视频 |

色片：**CTB**（偏冷蓝）、**CTO**（偏暖橙），用于校正或营造双色温。

选购时关注：照度、价格、便携、**发光面积**、**CRI / TLCI** 显色指数。

### 爱好级清单

- **方案 A**：闪光灯 + 灯架 + 引闪器（或灯棒作辅光）
- **方案 B**（家庭小棚）：两灯架 + 横杆 + 背景纸

### 反光板五面

| 面 | 作用 |
| --- | --- |
| 银 | 反光强 |
| 白 | 相对柔和 |
| 金 | 冷环境里给人物一点暖调 |
| 黑 | 吸光，加深阴影 |
| 半透明 | 正午硬光当天幕，柔化顶光 |

常亮示例：聚光灯 + 遮光片/反射布；便携如神牛 ML100Bi（Type-C/DC、聚光透镜）。

## 热靴灯入门

### 模式速查

| 功能 | 用途 |
| --- | --- |
| **TTL** | 自动测光闪灯，主体亮度随光圈变化自动补偿 |
| **M** | 手动功率，环境稳定时输出一致 |
| **Multi** | 频闪，特殊效果 |
| **TCM** | 记忆上次功率，固定场景重复拍摄 |
| **高速同步** | 快门很快时仍能同步闪光，晴朗户外压暗背景（卷帘快门可能果冻；全域快门无此限） |
| **Master / Slave** | 无线引闪；CH 频道配对 |
| **S1** | 光引闪，机顶闪 + M 档 |
| **S2** | 忽略预闪，避免误触发 |
| **Zoom** | 闪光覆盖范围，一般对齐镜头焦距 |
| **闪光补偿** | 类似曝光补偿，只调主体明暗 |

### 核心曝光公式

**手动 M 档：**

- **背景亮度** → 快门时间
- **主体亮度** → 闪光灯功率
- **光圈 / ISO** → 同时影响主体与环境

**TTL 档：**

- 缩小光圈时，闪灯会补偿以保持主体亮度
- 背景用曝光补偿，主体用闪光补偿

## 单灯实战

### 布光原则

1. 光要来自「逻辑光源」——观众觉得这里本该有灯。
2. 证件照模板：正面主光 + 背景过曝 + 泡沫板下巴反光。
3. 柔光附件：柔光伞、柔光罩、柔光屏；保荣口 + 转接环可扩展。入门优先柔光伞/罩。

### 直闪 vs 跳闪

| 方式 | 效果 | 适合 |
| --- | --- | --- |
| **直闪** | 硬朗建模，高光利落；易与背景割裂 | 正面朝镜头的模特、胶片/复古调色 |
| **跳闪** | 斜后上方打向天花板/墙面，光线柔和 | 日常人像、室内 |

### 夜景人像补光

器材由强到弱：

1. 热靴灯 + 柔光罩 + 灯架
2. LED 灯棒
3. 手电筒
4. 无灯：在环境里找已有光源

原则：**人脸亮度压过杂乱环境光**；灯位放在「可能有灯」的地方（路灯侧、橱窗旁等）。灯棒可摄像机后上方正面补脸，或侧面勾轮廓。

### 室外

逆光保天空时，天空容易过曝——用闪灯或反光板给人物补光，控制光比。

### 单灯灯位速查

| 灯位 | 要点 |
| --- | --- |
| **侧光** | 大光比：侧后、顶侧、底侧；小光比：前侧。深口径/格栅收束光 → 伦勃朗光 |
| **轮廓 / 发丝光** | 光从后方/侧后方来，发丝反光进镜头；户外可用太阳轮廓 + 正面反光板 |
| **正面** | 亮调：热靴 + 柔光伞；暗调：低功率填充 |
| **顶光 / 底光** | 特殊情绪；灯棒低机位补光 |

### 光比与光质

- **主光**：打亮主体，制造反差
- **轮廓光**：勾边
- **填充光**：避免面部死黑

功率关系：**主光 ＞ 轮廓光 ＞ 填充光**

### 色温法（一张闪灯压环境）

1. 机内白平衡设暖（如 2900K / 3900K）。
2. 闪光灯加 **CTO** 色片，与机内设定一致。
3. 结果：环境偏冷、人物肤色正常——只用一盏热靴灯也能分出层次。

1. 发光面积越大，光越柔。

5. 机内暖 K + CTO 色片 = 冷背景暖人物。
