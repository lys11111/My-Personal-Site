曝光、器材、题材、审美——摄影入门常被拆成四块碎片知识。这篇笔记把它们串成一条线：先搞懂相机怎么「看见」光线，再决定买什么、怎么拍、怎么修。

---

## 曝光三要素

曝光由三个参数共同决定：**光圈 F**、**快门 SS**、**ISO**。三者相互牵制，改一个往往要补偿另一个。

| 参数 | 控制什么 | 副作用 |
| --- | --- | --- |
| **光圈 F** | 进光量 & 景深 | F 越小（如 F1.4）进光越多、背景越虚；收 2–3 档往往是镜头最佳画质区 |
| **快门 SS** | 凝固程度 & 进光时长 | 越快越能冻结运动；越慢越易拖影 |
| **ISO** | 感光度 | 越高噪点越多、对比度与饱和度往往下降 |

**曝光补偿**是对三要素汇总结果的修正：**白加黑减**——画面偏亮时减补偿，偏暗时加补偿。

## 快门实战

### 安全快门

手持拍摄时，快门速度应不低于 **1/焦距**（或 1/2 倍焦距更稳妥）。被摄体移动快时，还要再提高快门。

### 慢门应用

- **拖影**：车流、人流
- **水面镜面**：长曝光让波纹消失
- **水流拉丝**：瀑布、溪流

需要 **三脚架**；强光下加 **ND 减光镜** 才能拉长时间。

### 摇摄

相机跟随移动主体同步平移，主体清晰、背景模糊。要点：关闭防抖、快门与主体速度匹配。

### 快门类型

| 类型 | 特点 | 适合 |
| --- | --- | --- |
| **机械快门** | 闪光同步可靠；无卷帘/门帘阴影 | 棚拍、闪光 |
| **电子快门** | 静音；卷帘快门可能有果冻效应 | 日常静音拍摄 |
| **全域快门** | 全像素同时曝光，无果冻 | 体育、新闻、高速闪光 |

**频闪**：国内 50Hz 电源下，快门选 **1/50** 或 **1/100** 可避免 banding。

## 测光与传感器

### 测光原理

相机测光以 **18% 灰** 为基准，试图把画面平均亮度还原到中间灰。

| 模式 | 行为 |
| --- | --- |
| **评价测光** | 全画面加权，日常默认 |
| **中心测光** | 偏重画面中央 |
| **点测光** | 只测小区域，逆光人像常用 |

曝光补偿与测光模式，最终都是通过调整三要素来修正曝光结果。

### CMOS 结构

- **前照式**：经典结构，低照度性能一般
- **背照式**：感光层更靠外，低照度更好
- **堆栈式**：信号处理电路后移，高感与速度兼顾

### 画幅

像素是画幅上的细分单元。**全画幅** vs **半画幅**（等效焦距 ×1.5 或 ×1.6）。全画幅通常背景虚化更好、高感更干净，但体积与价格更高。

### 宽容度与动态范围

**宽容度**：传感器能记录的明暗范围。**HDR**：多张不同曝光合成，扩展动态范围。拍 RAW 可保留更多高光与阴影细节，后期空间更大。

## 选购相机

### 类型

| 类型 | 特点 |
| --- | --- |
| **单反** | 光学取景，无视差；机身较重 |
| **无反** | 电子取景，所见即所得；体积相对小 |
| **卡片机** | 便携，一英寸或更小传感器 |

### 画幅阶梯

手机 → 1 英寸 → M43 → 半画幅 → 全画幅 → 中画幅

### 评判维度

- **传感器**：信噪比、宽容度、色彩深度、高感
- **体验**：屏幕、防抖、体积重量
- **输出**：直出 JPG 风格 vs RAW 工作流
- **参考**：DXO Mark 等第三方参数对比

全画幅在相同光圈下背景虚化更明显，最近对焦距离也往往更近。

## 镜头入门

### 变焦三元组

| 系列 | 典型焦段 | 特点 |
| --- | --- | --- |
| **大三元 F2.8** | 16-35 / 24-70 / 70-200 | 画质与光圈兼顾，贵且重 |
| **小三元 F4** | 同上焦段 | 更轻更便宜，光圈小一档 |

### 定焦推荐

- **85mm F1.8**：人像经典
- **35mm F1.4**：环境人像、扫街
- **百微**：微距、产品

### 焦段感

- **广角**：纵深感强，近大远小夸张
- **长焦**：压缩感，背景与主体「贴」在一起

注意：**透视由拍摄距离决定**，不是焦段本身。同一构图换焦段，需要后退或靠近。

### 景深三要素

1. **光圈** — 越大（F 越小）越浅
2. **焦段** — 越长越浅
3. **对焦距离** — 越近越浅

副厂镜头（腾龙、适马）与国产定焦，性价比往往更高。

## MTF 与光学

### 读 MTF 曲线

- **X 轴**：画面中心 → 边缘
- **Y 轴**：光学传递质量（0~1）
- **10 线/mm**：低周波对比度；>0.8 通常通透
- **30 线/mm**：高周波分辨率；0.6 为常见参考线
- **S/M 线**：弧矢（实线）/ 子午（虚线）；两线越接近，焦外过渡越自然

不同光圈、中心与边缘的表现会分开标注。买镜头前先看 MTF，心里有数。

### 光学缺陷

| 缺陷 | 表现 |
| --- | --- |
| **色散** | 高对比边缘紫/绿边 |
| **畸变** | 直线变弯，广角常见 |
| **暗角** | 四角变暗 |
| **炫光/鬼影** | 强光源下光斑、重影 |

### 焦外风格

旋焦、鱼鳞、多边形、甜甜圈（折返镜头）——与球差矫正程度有关。**缩 2 档光圈** 往往可减弱风格化焦外，获得更均匀虚化。

## 构图

### 核心思路

**决定性瞬间**——在正确的时间、位置按下快门。入门可从 **临摹** 开始：找喜欢的作品，分析机位、焦段、光线，再抽象成几何结构。

### 两条路径

| 路径 | 关注点 |
| --- | --- |
| **结构主义** | 几何、线条、色块、空间逻辑 |
| **内容主义** | 主体、故事、人文瞬间 |

### 透视与空间

近大远小由**距离**决定。广角强化纵深张力；长焦压缩空间层次。

**练习顺序**：先临摹 → 抽象几何 → 填入自己的主体。

灵感来源：[Behance](https://www.behance.net)、[500px](https://500px.com)、[CNU](https://www.cnu.cc)、画册与大师作品。

## 题材速查

| 题材 | 参数要点 |
| --- | --- |
| **风光** | F11+ 保景深；三脚架；偏振镜减反光 |
| **扫街** | 灵活快门；RAW；预判瞬间 |
| **人像** | 大光圈虚化；注意光比与肤色 |
| **星空** | 手动对焦；快门勿过长（否则星轨）；高 ISO + 大光圈 |

### 光比处理

现场光比过大时：

1. 拍 **RAW**，后期拉阴影/压高光
2. **补光**（闪灯、反光板）
3. **调角度**，避开极端逆光
4. 放弃亮部或暗部，保留一侧层次

特殊情况：摇摄或三脚架长曝光时**关闭防抖**；慢门加 ND；星空用手动对焦并对准无穷远附近。

## 审美与后期

### 全流程

**审美 → 想法 → 技法**

拍照没思路时，按顺序想：**题材**（拍什么）→ **构图**（怎么摆）→ **调色风格**（什么质感）。

### 后期思路

- **结构主义调色**：按明暗与色相分区，而非全局套滤镜
- **常见风格**：青橙、黑金等，建立个人识别度
- **RAW 工作流**：保留宽容度，非破坏性调整

## 记住这些

1. **曝光三要素**共同决定画面明暗；白加黑减修正整体。
2. **安全快门**防糊；慢门要脚架；摇摄关防抖。
3. **买相机**先看画幅与用途，别只看像素。
4. **买镜头**先看 MTF，再试焦外与畸变。
5. **构图从临摹开始**，先结构后内容。
6. **拍 RAW**，题材参数对照上表，后期空间更大。
